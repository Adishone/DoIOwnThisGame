What is GoG Galaxy and how do I get it? GOG Galaxy 2.0 is a wonderful concept of a PC games launcher that puts all your favourite games in one place. It's essentially a single library for all your games from Steam, Origin, UPlay and Epic Store, as well as games from GOG.com (naturally). Various integrations in GOG Galaxy 2.0 mean it works with 20 gaming platforms currently. To get it go to GoG Galaxy Site.
Where do I find GoG Galaxy Database? If you are using MAC, default database location will be /Users/Shared/GOG.com/Galaxy/Storage/galaxy-2.0.db
If you are using Windows, default database location will be C:\ProgramData\GOG.com\Galaxy\storage\galaxy-2.0.db
ProgramData is hidden folder, so you can have problems with finding it on your disk.
How to get CSV file with my games? In Playnite you would need addon to export your games list to CSV: https://playnite.link/addons.html#LibraryExporter_54bf64c6-c453-4cbc-92f8-4960b56f930e. Uncheck all fields when exporting as only names are needed.
How to obtain Steam Api Key? First step to get your own Steam API credentials is to have an Steam Account. To do that you need to access this page https://store.steampowered.com/join, and fill the requested information. You will need to agree with the Steam Api Terms of Use, and that you should have spend more than 5.00 USD in the Steam Store to be able to get the API key. Always keep your steam api key as secret.
